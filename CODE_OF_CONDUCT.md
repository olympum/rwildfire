# Code of conduct

This project welcomes contributions from people of all backgrounds and experience levels. Discuss the work on its merits, give feedback that people can act on, and respect requests to stop an interaction.

Harassment, threats, discriminatory insults, sexual harassment, and sharing someone’s private information without permission are not acceptable. This applies to issues, pull requests, reviews, and other project spaces.

Report concerns privately to the maintainer using the public contact on [@olympum’s GitHub profile](https://github.com/olympum). Include links or context if you can. Do not post private details in an issue. You can also use [GitHub’s abuse reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) for platform violations. If the report concerns the maintainer, use GitHub’s reporting tools instead.

Maintainers may remove content, warn contributors, restrict participation, or block accounts, depending on the severity or recurrence of the behavior. They should share identifying information only as needed to investigate or respond.
