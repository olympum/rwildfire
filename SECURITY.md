# Security policy

rwildfire is an early preview. Security fixes target the current default branch; older snapshots are not maintained separately.

Report suspected vulnerabilities through [GitHub’s private reporting form](https://github.com/olympum/rwildfire/security/advisories/new), not a public issue or pull request. Include the affected commit, platform, steps to reproduce, and potential impact. Remove secrets and personal data from attachments. Please coordinate disclosure with the maintainers before publishing details.

For ordinary bugs or parity differences, use the [issue templates](https://github.com/olympum/rwildfire/issues/new/choose).
